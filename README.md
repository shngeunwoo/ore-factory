# ORE FACTORY

**캐고 · 굽고 · 레일로 판다.**

광석을 캐고, 화로에 굽고, 레일로 실어 파는 격자 공장 게임.

손에 흙을 묻히는 채굴에서 시작한다. 상점에 팔아 크레딧을 모으고, 레일 위에 화로를 올려 주괴를 뽑는다. 채굴기가 땅을 대신 파고, 창고와 분배기가 화물 흐름을 나눈다. 연구를 열고 전력을 이으면 더 뜨거운 설비와 더 먼 광맥이 열린다. 맵 끝은 돈으로 한 줄씩 산다.

**[플레이](https://shngeunwoo.github.io/ore-factory/)**

## 공장

채굴하고, 팔고, 제련하고, 자동화한다.

광석을 길게 눌러 캔다. 상점 옆 레일은 화물을 알아서 판다. 레일 위 화로가 석탄과 원광을 주괴로 바꾸고, 채굴기·창고·필터·전봇대·연구소로 손 없이 돌아가는 공장을 짓는다. 가장자리를 사들여 부지를 넓힌다.

## 조작

- 광석을 길게 누르면 채굴한다
- 설비나 레일을 누르면 방향·연료·업그레이드를 본다
- 바닥의 화물은 클릭해서 줍는다
- 레일은 누른 채 끌어 이어서 놓는다
- 우클릭이나 Esc로 도구를 내린다
