# 게임 설계

밸런스 숫자의 SSOT는 코드 `src/js/domain/recipes.js`. 이 문서는 규칙만.

## 광석

| 티어 | 종류 | 맵 |
|------|------|-----|
| 1 | 돌, 석탄, 철, 구리 | 시작부터 |
| 2 | 주석, 아연, 납 | 확장 2회부터 |
| 3 | 니켈, 은, 금 | 확장 5회부터 |

- 채굴·채굴기 모두 원광 1 + **50% 돌**
- 채굴기가 설치된 광석은 수동 채굴할 수 없다
- 시작 9×9는 기본 4종 확정 배치, 상점 주변은 빈 땅(레일·화로용). 광석은 서로 붙지 않게 떨어뜨린다
- 확장 줄은 약 78% 빈 칸이며 랜덤 광석은 기본 4종만 간격을 두고 나온다
- 중급 3종은 확장 2회째, 고급 3종은 확장 5회째에 **종류당 1칸만** 확정 스폰한다. 이후 줄에 반복하지 않는다

## 상점

- 첫 상점 중심 `(4,4)`, 발자국 3×3
- 축마다 9칸마다 추가 상점
- 상점 칸에는 일반 건물 설치 불가
- 레일이 상점 이웃에 붙으면 화물 자동 판매
- 자동 판매도 발견·판매 통계에 반영한다

## 물류 v2

- 레일은 상점 연결 여부와 무관하게 열린 포트 사이로 화물을 운송한다.
- 수동 출력 방향이 우선한다. `AUTO`는 진입 반대편의 직진을 먼저 고르고 나머지 분기를 순환한다.
- 연결된 출구가 없으면 화물은 현재 칸의 바닥 스택으로 떨어진다. 연결은 있지만 다음 칸이 차 있으면 대기한다.
- 바닥 스택은 종류별로 합쳐지며 플레이어가 타일을 클릭하면 전량 회수한다.
- 정체되거나 전력이 끊겨 멈춘 레일 화물은 타일을 길게 눌러 직접 회수한다. 이동 가능한 화물은 회수할 수 없다.
- 타일은 `rail`, `building`, `cargo`, `groundItems`를 따로 보관한다. 레일과 인라인 설비는 같은 칸을 쓸 수 있다.
- 화로는 레일 위에 설치한다. 석탄 화물은 연료 버퍼로, 원광 화물은 제련 슬롯으로 들어가며 완성 주괴는 같은 레일에 다시 놓인다.
- 창고는 화물을 용량 제한 없이 저장하고 빈 인접 레일로 다시 배출한다. 창고 타일을 길게 누르면 내용물을 전량 회수한다.
- 필터 분배기는 북·동·남·서 각 방향에 화물을 지정한다. 일치 화물은 해당 방향으로 분배하고 미지정 화물은 일반 `AUTO` 흐름을 따른다.
- 채굴기는 출력 방향을 `AUTO` 또는 `↑ → ↓ ←`로 지정한다. 화살표와 열린 포트가 일치하는 레일에만 연결·배출하며 점유된 레일이면 대기한다.

## 건물

| 종류 | 설치 칸 | 해금 |
|------|---------|------|
| 레일 T1–3 | 빈 칸 | T1 시작부터, 상위 티어 연구 |
| 인라인 화로 T1–3 | **레일 칸** (`place: rail`) | 제련 연구 |
| 채굴기 T1–3 | **광석 칸** (`place: ore`) | 자동화 연구 후 주괴·돌 |
| 창고 | 빈 칸 | 물류 연구 |
| 필터 분배기 | **레일 칸** | 분배 연구 |
| 석탄 발전기·배터리 | 빈 칸 | 전력 연구 |
| 전봇대 | 모든 칸, 다른 레이어와 중첩 | 전력 연구 |
| 연구소 | 빈 칸 | 연구 자동화 연구 |

- 설치 모드는 같은 버튼/우클릭/Esc로 취소. 재료 없어도 취소 가능
- 레일은 누른 채 드래그해 연속 설치할 수 있다. 터치도 같다
- 철거 시 설치 재료와 건물 안의 자원·화물을 전액 회수한다
- 인라인 화로는 레일 화물을 자동 처리하며 패널에서 석탄을 직접 보충할 수도 있다
- 화로가 받을 수 없는 화물은 기본적으로 인라인 화로 칸에 정체된다. 각 화로 검사 패널의 토글로 해당 화로만 통과 모드로 바꿀 수 있다
- 레일은 연결된 포트와 출력 규칙만 사용한다. 상점 BFS는 사용하지 않는다
- 각 레일의 북·동·남·서 포트를 개별로 켜고 끌 수 있다. 레일끼리는 양쪽 포트가 모두 열려야 연결된다
- 출구를 `자동` 또는 특정 방향으로 지정할 수 있다. 수동 출구는 자동 흐름보다 우선한다
- 상점 방향 포트가 열린 레일에서 상점으로 나가면 화물을 판매한다
- 연결되지 않은 레일은 드롭 출구, 막힌 레일은 정체 상태로 표시한다

## 연구·퀘스트·업그레이드

- 연구점은 퀘스트 보상과 가동 중인 연구소에서 얻는다.
- 기술은 선행 기술과 연구점 비용을 요구하며 건물·상위 티어를 해금한다.
- 퀘스트는 채굴·판매·운송·제련·발전·연구 이벤트를 추적하고 완료 즉시 보상한다.
- 설치된 설비는 패널에서 다음 티어로 업그레이드한다. 내용물·진행률·레일 설정은 보존한다.
- 연구소는 연구점 1점을 완성할 때마다 코드에 정의된 대량의 돌·석탄·철 주괴·구리 주괴를 소비한다. 자원이 부족하면 진행률 100%에서 대기한다.

## 전력

- 발전기·전봇대·배터리와 인접 소비 설비가 지역 전력망을 만든다.
- 전봇대는 별도 `powerNode` 레이어라 광석·레일·설비와 겹쳐 어디든 설치할 수 있다. 일반 철거와 분리된 전력 철거 도구(`P`)로만 제거한다.
- 발전기는 석탄 연료를 소비한다. 배터리는 잉여 전력을 저장하고 부족할 때 방전한다.
- 레일·채굴기·화로 T1은 전력 없이 작동한다. T2부터 전력을 소비하고 T3는 T2보다 더 많이 소비한다.
- 전력이 부족하면 연구소와 전력을 쓰는 레일·채굴기·화로가 공급 비율만큼 감속하며 공급이 없으면 정지한다.
- 같은 칸의 인라인 설비와 레일은 전력 수요를 각각 계산하며 검사 패널에서 소비량·공급률을 확인한다.

## 확장

비용 `$20 × 1.5^n` (`expandCost`). 동서남북 한 줄.

## 시작 보급

돈 $25, 돌 30, 석탄 6.

첫 실행 시 4단계 튜토리얼 카드가 현재 할 일만 보여 준다. 채굴 → 판매 → 화로 제련 → 레일/자동화. 건너뛰기는 이번 세션만 유지되고, 새로고침하면 다시 나온다. OF2 저장 코드를 불러오면 건너뛰기 설정도 복원된다.

## 저장

- 브라우저는 진행을 저장하지 않는다. 새로고침·초기화하면 시작 공장으로 돌아간다.
- 설정에서 현재 공장을 `OF2` 휴대용 코드로 만들거나 `.txt` 파일로 저장한다. 붙여넣기와 파일 열기 모두로 복원한다.
- 저장 코드는 서버로 전송하지 않으며 Base64URL 인코딩과 체크섬으로 형식·손상을 검증한다. 비밀번호 기반 보안 암호화는 아니다.
- 예전 `localStorage` 키가 남아 있으면 시작 시 지운다.
